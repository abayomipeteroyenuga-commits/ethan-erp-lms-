LESSON 1: GETTING STARTED WITH MICROSOFT WORD
Introduction
Microsoft Word is a word-processing program designed for producing written documents. Unlike a plain text
editor, Word provides tools for formatting, page design, tables, graphics, references, reviewing and
professional printing.

What Word Is Used For
 Letters and memos
 School assignments and projects
 CVs and résumés
 Reports and proposals
 Minutes of meetings
 Invoices and simple forms
 Training manuals and newsletters

Word Processing Concepts
A document is the file you create. Word allows the document to contain text and other objects such as tables,
pictures, charts, shapes and hyperlinks. Most modern Word documents are saved in DOCX format.

Starting and Closing Word
Word can be opened from the Start menu, desktop shortcut or an existing Word file. Before closing, save
important changes. If Word asks whether to save unsaved work, read the prompt carefully.

Step-by-Step Practical
1. Open Microsoft Word.
2. Choose Blank document.
3. Type: My First Professional Word Document.
4. Press Enter twice and type a short paragraph about Ethan Digital Academy.
5. Use Ctrl+S, choose a folder, name the file EDA-Word-Practice-01.docx and save.
6. Close Word and reopen the saved file.

Real-Life Application / Case Study
A new office assistant is asked to type a one-page meeting notice. Understanding how to start Word, create a
document and save it correctly prevents loss of work and creates an organized record.

Review Questions
7. What is word processing?
8. Mention five documents that can be created in Word.
9. What is the common modern Word file extension?
10. Why should a document be saved early?

Assignment

meaningful filename.

 

LESSON 2: UNDERSTANDING THE WORD INTERFACE

 Figure 1. Instructional visual for Understanding The Word Interface.

Introduction
The Word interface is the working environment containing commands, document controls and the page on
which content is created.

Major Parts of the Interface
 Title Bar - displays the document and application name.
 Quick Access Toolbar - provides frequently used commands such as Save and Undo.
 File tab - opens Backstage view for saving, printing, sharing and options.
 Ribbon - organizes commands into tabs and groups.
 Document area - the page where content is entered.
 Ruler - assists with margins, indents and tabs.
 Status Bar - displays page, word and view information.
 Scroll bars - move through the document.
 Zoom control - changes the viewing size without changing printed font size.

Ribbon Tabs
Common tabs include Home, Insert, Design, Layout, References, Mailings, Review and View. Each tab
groups related commands. The exact interface can vary slightly by Word version.

Views and Zoom
Print Layout is commonly used for document creation because it approximates the printed page. Zoom
affects only the on-screen view.

Step-by-Step Practical
11. Open a blank document.

 

12. Identify the Title Bar, Ribbon, ruler, document area, status bar and zoom control.
13. Click Home, Insert, Layout, References and Review and observe how the commands change.
14. Change zoom to 80%, then 120%, and return to a comfortable level.
15. Use the View tab to inspect available document views.

Real-Life Application / Case Study
A learner who knows where commands are located spends less time searching and can follow workplace
instructions more confidently.

Review Questions
16. What is the Ribbon?
17. What is the purpose of the Status Bar?
18. Does zoom change the actual font size?
19. Name five Ribbon tabs.

Assignment

LESSON 3: CREATING, OPENING, SAVING AND ORGANIZING
DOCUMENTS

 Figure 2. Instructional visual for Creating, Opening, Saving And Organizing Documents.

Introduction
Professional document work requires both writing skills and reliable file management.

New and Existing Documents
New creates a fresh document; Open retrieves an existing document. Recent files can speed up access, but
important files should still be stored in organized folders.

Save and Save As
Save updates the current file. Save As creates a new copy, changes the filename, changes the location or
chooses another format.

Common Formats
 DOCX - standard editable Word document.
 PDF - fixed-layout format useful for distribution.
 TXT - plain text without Word formatting.
 RTF - rich text format supported by many word processors.

File Organization
Use folders and meaningful names such as EDA_Training_Report_September_2026.docx instead of
Document1.docx. Avoid creating unnecessary duplicate versions.

Step-by-Step Practical

24. Export or save an additional PDF copy if your Word version provides that option.

Real-Life Application / Case Study

problem.

LESSON 4: TEXT ENTRY, SELECTION AND EDITING
Introduction
Editing means changing document content accurately and efficiently.

Insertion Point and Selection
The blinking insertion point shows where new text will appear. Text can be selected with the mouse or
keyboard before formatting, moving or deleting it.

Core Editing Commands
 Copy duplicates selected content.
 Cut removes selected content and places it on the Clipboard.
 Paste inserts Clipboard content.
 Undo reverses a recent action.
 Redo repeats or restores an undone action.
 Find locates words or phrases.
 Replace changes repeated text efficiently.

Useful Shortcuts
 Ctrl+C - Copy
 Ctrl+X - Cut
 Ctrl+V - Paste
 Ctrl+Z - Undo
 Ctrl+Y - Redo
 Ctrl+A - Select All
 Ctrl+F - Find
 Ctrl+H - Replace

Step-by-Step Practical
29. Type three short paragraphs.
30. Select the second paragraph and copy it below the third.
31. Cut one sentence and paste it at the beginning.
32. Use Undo and Redo.
33. Use Find to locate a repeated word.
34. Use Replace to change that word throughout the practice document.

Real-Life Application / Case Study
An administrator receives a report in which the old department name appears 25 times. Find and Replace
can update the document quickly, but the replacement should be reviewed to ensure every change is
appropriate.

Review Questions

LESSON 6: PARAGRAPH FORMATTING
Introduction
Paragraph formatting controls how complete paragraphs are positioned and spaced on the page.

Alignment
 Left - common for general text.
 Center - useful for selected headings.
 Right - sometimes used for dates or special layouts.
 Justify - aligns text to both left and right margins.

Spacing and Indentation
Line spacing controls distance between lines. Paragraph spacing controls space before or after paragraphs.
Indents move paragraph edges inward.

Bullets and Numbering
Bullets are useful for unordered items; numbering is useful when sequence or priority matters.

Borders and Shading
Borders and shading can emphasize selected paragraphs, but should be applied sparingly.

Step-by-Step Practical

Real-Life Application / Case Study

LESSON 7: PAGE LAYOUT AND DOCUMENT SETUP

 Figure 4. Instructional visual for Page Layout And Document Setup.

Introduction
Page layout determines the physical structure of the document page.

Margins
Margins are the blank spaces around page content. Standard professional margins are suitable for most
documents, while special documents may require custom margins.

Orientation and Size
Portrait is taller than it is wide; landscape is wider than it is tall. A4 is commonly used for office and academic
documents in many countries.

Breaks
A page break moves following content to a new page. Section breaks allow different formatting in different
sections, such as orientation, headers or columns.

Columns
Columns can be used for newsletters, brochures and selected layouts.

Step-by-Step Practical
