Lesson 1: Introduction to Databases and Microsoft Access
Introduction
A database is an organised collection of related information. Microsoft Access is a relational database
application that helps users store, connect, retrieve and present structured records. Unlike a simple list, a
relational database can separate information into logical tables and connect those tables through keys.

Learning Objectives
 Explain the main ideas in introduction to databases and microsoft access.
 Apply the lesson using a safe fictional Ethan Digital Academy dataset.
 Check the accuracy of the result and explain why the method is useful.

Key Terms
Database, Relational Database, Record, Field, Table, Database Management System.

Teaching Content
Microsoft Access works best when information is organised deliberately. A learner should always ask what
each table represents, what each field means, and how the information will be used later. Clear structure is
more important than entering a large quantity of data.

Professional database work depends on consistency. Names, dates, codes and money values should follow
agreed rules. When the structure is consistent, queries and reports become more reliable and users can
understand the database more easily.

A database object should have a clear purpose. Before creating or changing an object, identify the question
it solves. After the change, test the object with fictional records and confirm that the output matches the
intended business rule.
