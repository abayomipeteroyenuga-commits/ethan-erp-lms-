Course Introduction
Computer Hardware Fundamentals explains the physical components that make computers work. Learners
study system types, motherboards, processors, memory, storage, input/output devices, ports, power,
cooling, graphics, networking, specifications, upgrades, basic troubleshooting and preventive care.

Learning Objectives
 Identify major internal and external hardware components.
 Explain the purpose of CPU, RAM, storage, motherboard and peripherals.
 Recognise common ports and device categories.
 Read computer specifications and match them to workloads.
 Compare desktops and laptops.
 Apply safe basic troubleshooting and preventive-care principles.
 Plan a suitable computer system for a realistic use case.

Lesson 1: Introduction to Computer Hardware
Introduction
Computer hardware refers to the physical parts of a computer system that can be seen or touched.
Hardware works together with software to receive input, process data, store information and produce output.

Learning Objectives
 Explain the major concepts in introduction to computer hardware.
 Complete the safe guided practical for introduction to computer hardware.
 Relate hardware choices to real academic and workplace needs.

Teaching Content
Key point: Core hardware groups include input, processing, memory, storage and output.

Key point: Internal components are housed inside the computer while peripherals connect externally.

Key point: Hardware choices should match the intended workload.

Key point: Users should not open powered equipment or attempt electrical repairs during beginner training.

 Figure 1: Instructional visual for Introduction to Computer Hardware.

Step-by-Step Guided Practical
1. Identify a desktop or laptop computer.
 

 
2. List five visible hardware components.

3. Classify each as input, output, storage or processing-related.

4. Explain one difference between hardware and software.

Lesson 6: Storage Devices: SSD, HDD and
Removable Media
Introduction
Storage keeps files and software when the computer is powered off. Common technologies include solid-
state drives and hard disk drives.

Learning Objectives
 Explain the major concepts in storage devices: ssd, hdd and removable media.
 Complete the safe guided practical for storage devices: ssd, hdd and removable media.
 Relate hardware choices to real academic and workplace needs.

Teaching Content
Key point: SSDs use flash memory and generally provide faster access with no moving read/write
mechanism.

Key point: HDDs store data magnetically on rotating platters and can offer large capacity at lower cost.

Key point: USB flash drives and memory cards are removable storage but should not be the only copy of
important work.

Key point: Storage capacity and performance are separate considerations.

Step-by-Step Guided Practical
1. Open File Explorer or the system storage page.

2. Record the main drive's total and free capacity.

3. Identify whether the system reports SSD/HDD where available.

4. Copy a harmless practice file to an authorised removable drive, then safely eject it.

Lesson 17: Basic Hardware Troubleshooting
Introduction
Basic troubleshooting is a structured process of identifying symptoms, checking simple causes and
escalating when specialist repair is required.

Learning Objectives
 Explain the major concepts in basic hardware troubleshooting.
 Complete the safe guided practical for basic hardware troubleshooting.
 Relate hardware choices to real academic and workplace needs.

Teaching Content
Key point: Describe the symptom precisely: no power, no display, no sound, no network, or slow
performance.

Key point: Check safe external factors first, such as power, cables, brightness, volume and normal settings.

Key point: Restarting through the operating system can resolve some temporary problems.

Key point: Change one safe variable at a time so the cause is easier to identify.

Key point: Stop and escalate if there is burning smell, damaged power equipment, liquid exposure or a
repair requiring internal electrical work.

Professional Practice Checklist
 Never open powered equipment during beginner practicals.
 Never force connectors into ports.
 Match hardware to workload and compatibility requirements.
 Protect equipment with appropriate power practices.
 Keep ventilation clear.
 Back up important data.
 Escalate electrical or internal hardware faults to qualified personnel.
