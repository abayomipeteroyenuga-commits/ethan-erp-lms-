FILE MANAGEMENT & CLOUD STORAGE

FULL VISUAL STUDY MANUAL

Practical work should use authorised accounts and harmless practice files. Never share passwords or one-time codes, expose private files through public links, or delete important data while practising.

Course Introduction

This course teaches learners how to create a reliable digital filing system and use cloud storage responsibly. It combines local file organisation with synchronisation, sharing, collaboration, backup, recovery, privacy and cross-device workflows.

Learning Objectives

Explain files, folders, paths, formats and storage locations.

Design clear folder structures and naming conventions.

Search, sort, move, copy, archive and recover files safely.

Explain local, external, synced and cloud storage.

Use cloud sharing permissions appropriately.

Understand synchronisation, version history and offline files.

Create and test a basic backup and recovery plan.

Apply account security and privacy to cloud storage.

Complete an end-to-end digital filing project.

Lesson 1: Introduction to File Management and Cloud Storage

Introduction

File management is the organised creation, naming, storage, retrieval, sharing, protection and archiving of digital information. Cloud storage adds online access and synchronisation across authorised devices.

Learning Objectives

Explain the main principles of introduction to file management and cloud storage.

Complete a guided practical for introduction to file management and cloud storage.

Apply the lesson to a realistic study or office workflow.

Teaching Content

Key point: A file is a named unit of digital information; a folder groups files and other folders.

Key point: Good organisation reduces time wasted searching and lowers the risk of using the wrong version.

Key point: Storage location matters: a file may be local, synchronised, cloud-only or backed up elsewhere.

Key point: Cloud services are useful, but users still need naming, permissions, backup and security habits.

Lesson 4: File Types, Extensions and Formats

Introduction

Learning Objectives

Explain the main principles of file types, extensions and formats.

Complete a guided practical for file types, extensions and formats.

Apply the lesson to a realistic study or office workflow.

Teaching Content

Key point: DOCX is commonly used for editable word-processing documents.

Key point: XLSX stores spreadsheet workbooks; PPTX stores presentations.

Key point: PDF preserves a fixed page layout for viewing and printing.

Key point: JPG and PNG are common image formats; ZIP packages multiple files into a compressed archive.

Know where important files are stored.

Use the least sharing permission required.

Test recovery using harmless practice files.
