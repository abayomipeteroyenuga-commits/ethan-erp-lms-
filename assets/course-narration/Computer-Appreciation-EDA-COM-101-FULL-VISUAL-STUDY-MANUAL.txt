MODULE 1: INTRODUCTION TO COMPUTERS
What is a Computer?
A computer is an electronic device that receives data, processes it according to instructions, stores
information and produces useful output.

 Figure 1. Input, processing, storage and output.

The Information-Processing Cycle
The basic cycle is Input -> Processing -> Storage -> Output. Input devices enter data, the processor works on
the data, storage keeps data and programs, and output devices present the result.

Characteristics of Computers
Computers are valued for speed, accuracy, storage capacity, automation, reliability and versatility. They can
repeat tasks consistently when given correct instructions and data.

Advantages
 Saves time
 Reduces many manual errors
 Stores large amounts of information
 Improves communication
 Supports online learning and business

Limitations and Risks
 Depends on electricity or battery power
 Can be affected by malware and cyber attacks
 Incorrect input can produce incorrect output
 Overdependence can reduce good work habits

MODULE 2: HISTORY OF COMPUTERS
From Mechanical Calculation to Modern Computing
Computing developed from early counting and mechanical devices to electronic systems that became smaller,
faster and more intelligent.

 Figure 2. Five generations of computer development.

First Generation (1940-1956)
 Used vacuum tubes
 Very large and produced much heat
 Consumed large amounts of electricity
 ENIAC is a well-known example

Second Generation
Transistors replaced many vacuum tubes, making computers smaller, faster and more reliable.

Third Generation
Integrated circuits placed many electronic components on small chips.

Fourth Generation
Microprocessors supported the rise of personal computers and portable devices.

Fifth Generation
Modern computing increasingly uses artificial intelligence, machine learning, robotics and advanced natural-
language systems.

 

Charles Babbage
Charles Babbage designed the Analytical Engine and is commonly described as the Father of the Computer.

MODULE 3: TYPES OF COMPUTERS
Computers can be classified in several ways.
A useful beginner classification considers size/capacity and purpose.

 Figure 3. Examples of computer types and purposes.

Supercomputers
Extremely powerful systems used for scientific research, simulations and weather modelling.

Mainframes
Large systems designed to process very high volumes of transactions and support many users, often in banks
and government organizations.

Microcomputers
Computers designed for individual use, including desktops, laptops, tablets and smartphones.

General-Purpose Computers
Designed to perform many different tasks, such as a laptop used for writing, browsing, spreadsheets and
communication.

Special-Purpose Computers
Designed mainly for a specific task or limited set of tasks, such as some ATM or embedded control systems.

MODULE 4: COMPUTER HARDWARE
What is Hardware?
Hardware refers to the physical parts of a computer that can be seen or touched.

 Figure 4. Major computer hardware categories.

Input Devices
 Keyboard
 Mouse
 Scanner
 Webcam
 Microphone

Processing Devices
The CPU executes instructions and performs arithmetic, logical and control operations. Key concepts include
the Arithmetic and Logic Unit, Control Unit and registers.

Primary Storage
 RAM temporarily holds active data and programs.
 ROM stores non-volatile instructions or firmware-related information.

Secondary Storage
 Hard Disk Drive (HDD)
 Solid State Drive (SSD)
 Flash drive
 Memory card

 

Output Devices
 Monitor
 Printer
 Speakers
 Projector

Motherboard
The motherboard is the main circuit board connecting the processor, memory, storage interfaces, expansion
components and power connections.

MODULE 5: COMPUTER SOFTWARE
What is Software?
Software consists of programs and instructions that tell computer hardware what to do.

 Figure 5. System, application and utility software.

System Software
System software manages and supports the computer. Operating systems such as Windows, Linux and
macOS are key examples.

Application Software
Application software helps users perform tasks. Examples include Microsoft Word, Excel, web browsers and
graphics applications.

Utility Software
Utilities help maintain, protect or manage the system. Examples include antivirus, backup and disk-
management tools.

Hardware and Software Relationship
Hardware provides the physical equipment; software provides the instructions. A useful computer system
normally requires both.

MODULE 7: WINDOWS PRACTICAL
Working with the Windows Desktop
Windows provides a graphical desktop environment for launching applications, managing files and controlling
the computer.

 Figure 7. Simplified Windows desktop showing key areas.

Desktop
The desktop is the main workspace. It may contain shortcuts, folders and the Recycle Bin.

Taskbar and Start Menu
The taskbar provides access to open or pinned applications. The Start menu provides access to apps, search,
settings and power options.

Essential Shortcuts
 Ctrl+C - Copy
 Ctrl+V - Paste
 Ctrl+X - Cut
 Ctrl+Z - Undo
 Ctrl+S - Save
 Ctrl+A - Select All
 Ctrl+P - Print
 Alt+Tab - Switch between open apps
 Windows+D - Show desktop

Safe Practice
Avoid deleting unknown system files or changing advanced settings during beginner practice.

MODULE 11: CYBERSECURITY
What is Cybersecurity?
Cybersecurity is the practice of protecting computers, accounts, networks and information from unauthorized
access, damage and other digital threats.

 Figure 11. Common cyber threats and basic protective habits.

Common Threats
 Virus - malicious code that can damage or disrupt systems
 Malware - general term for harmful software
 Phishing - deceptive messages designed to trick people into revealing information or taking unsafe
 actions
 Ransomware - malware that can block access to files or systems

Basic Protection
 Use strong, unique passwords
 Enable two-factor authentication where available
 Keep software updated
 Use trusted security tools
 Avoid suspicious links and unexpected attachments
 Back up important files

Password Practice
A strong password or passphrase should be difficult to guess and should not be reused across important
accounts. Do not share passwords in class exercises.

MODULE 12: CLOUD COMPUTING AND AI
Cloud computing and artificial intelligence are important parts of modern digital work.
Cloud services allow data and applications to be accessed over networks, while AI systems can assist with
tasks such as summarising, generating ideas and analysing information.

 Figure 12. Cloud storage and AI as complementary digital-work tools.

Cloud Computing
Cloud storage services can make files available across devices and support backup and collaboration.
Examples include Google Drive, OneDrive and Dropbox.

Benefits of Cloud Services
 Access from multiple devices
 Backup and recovery support
 Sharing and collaboration
 Reduced dependence on one local device

Artificial Intelligence
AI enables computer systems to perform tasks associated with human intelligence, such as recognising
patterns, understanding language and generating content.

Responsible AI Use
 Verify important information
 Do not present AI-generated work as your own when rules prohibit it
 Protect private or confidential information
 Use AI as an assistant, not a substitute for judgment
 Follow school, workplace and platform rules
