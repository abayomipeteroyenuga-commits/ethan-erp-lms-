Course Introduction
Google Workspace brings communication, cloud storage, document creation, spreadsheets, presentations,
forms, scheduling and online meetings into one connected environment. This course teaches learners how
to use the major tools confidently for school, work, business and collaborative projects.

Learning Objectives
 Navigate the main Google Workspace tools and understand what each one is for.
 Organise and share cloud files responsibly using Google Drive.
 Create professional documents, spreadsheets and presentations.
 Collect structured information with Forms and manage schedules with Calendar.
 Communicate professionally with Gmail and participate effectively in Meet.
 Combine several Workspace tools into a practical academic or workplace workflow.

Lesson 1: Introduction to Google Workspace
Introduction
Google Workspace is a collection of cloud-based productivity and collaboration tools. It allows learners,
schools and organisations to communicate, create documents, analyse information, make presentations,
store files and work together from connected devices.

Learning Objectives
 Explain the key ideas in introduction to google workspace.
 Apply the lesson in a guided Google Workspace practical.
 Use good organisation, collaboration and information-handling practice.

Teaching Content
Key point: Cloud productivity means your work can be stored online and accessed from supported devices
after signing in.

Key point: Major Workspace tools include Gmail, Drive, Docs, Sheets, Slides, Forms, Calendar and Meet.

Key point: A Google Account provides identity and access. Organisational Workspace accounts may have
additional controls managed by an administrator.

Key point: Workspace is especially useful when several people need to work on the same information
without passing many file copies around.

 Figure 1: Instructional view for Introduction to Google Workspace.

1. Sign in to a practice Google Account.

2. Open the Google apps launcher.

3. Identify Gmail, Drive, Docs, Sheets, Slides, Calendar and Meet.

4. Write one business or school use for each tool.

Lesson 2: Google Accounts, Sign-In and
Account Safety
Introduction
A Google Account is the identity used to access Google services. Good account security protects email,
files, calendars and other connected information.

Learning Objectives
 Explain the key ideas in google accounts, sign-in and account safety.
 Apply the lesson in a guided Google Workspace practical.
 Use good organisation, collaboration and information-handling practice.

Teaching Content
Key point: Use a strong, unique password and never share it with classmates or colleagues.

Key point: Enable multi-factor authentication when available.

Key point: Check the account name before uploading private or organisational files.

Key point: Sign out on shared computers and avoid saving passwords on public devices.

Key point: Recovery information should be kept current so legitimate account recovery is easier.

Step-by-Step Guided Practical
1. Open the Google Account page from the profile menu.

2. Review basic security options without changing settings you do not understand.

3. Check whether you are using a personal or school/work account.

4. Practise signing out and signing in again on your own device.

Lesson 4: Sharing Files and Managing
Permissions
Introduction
Sharing allows other people to access a Drive file without sending separate copies. Permission choice
determines what each collaborator can do.

Learning Objectives
 Explain the key ideas in sharing files and managing permissions.
 Apply the lesson in a guided Google Workspace practical.
 Use good organisation, collaboration and information-handling practice.

Teaching Content
Key point: Viewer access is appropriate when a person only needs to read.

Key point: Commenter access supports feedback without direct editing.

Key point: Editor access should be limited to people who genuinely need to change content.

Key point: Restricted sharing is safer for internal or sensitive material.

Key point: Before sending a link, confirm both the recipient and the permission level.

 Figure 4: Instructional view for Sharing Files and Managing Permissions.

1. Create a practice Doc.

2. Open Share and inspect the available roles.

3. Choose Restricted sharing for the exercise.

4. Explain what would happen if Viewer were changed to Editor.

5. Do not share personal information as part of the practical.

Lesson 8: Google Sheets - Formulas and

Teaching Content
Key point: Arithmetic formulas can add, subtract, multiply and divide cell values.

Key point: SUM adds a range of numbers.

Lesson 9: Google Sheets - Data Organisation,
Charts and Analysis
Introduction
Good spreadsheet analysis starts with clean, well-organised data. Charts then help communicate patterns,
comparisons and trends.

Learning Objectives
 Explain the key ideas in google sheets - data organisation, charts and analysis.
 Apply the lesson in a guided Google Workspace practical.
 Use good organisation, collaboration and information-handling practice.

Teaching Content
Key point: Keep one type of information per column.

Key point: Avoid blank rows inside a continuous dataset unless there is a clear reason.

Key point: Sort changes record order; filtering temporarily hides records that do not match criteria.

Course Completion Outcome
After successfully completing this course, the learner should be able to use the major Google Workspace
applications for everyday academic and workplace productivity; organise and share files responsibly; create
collaborative documents, spreadsheets and presentations; collect structured responses; schedule activities;
communicate professionally; and combine Workspace tools into a coherent project workflow.

Professional Practice Checklist
 Use strong account-security habits.
 Keep Drive folders and file names organised.
 Share only with the access level required.
 Use fictional or authorised data during training.
 Check formulas, recipients, attachments and permissions before final submission.
 Maintain professional communication and collaboration standards.
