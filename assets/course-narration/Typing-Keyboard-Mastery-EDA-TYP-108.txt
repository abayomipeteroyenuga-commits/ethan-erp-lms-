Course Introduction
Typing is a core digital skill used in documents, spreadsheets, email, online forms, coding and business
administration. This manual teaches keyboard layout, touch-typing foundations, letters, numbers,
punctuation, navigation, shortcuts, accuracy, speed measurement and professional copy typing.

Learning Objectives
 Identify major keyboard sections and important keys.
 Use correct home-row finger placement and controlled typing technique.
 Type letters, numbers, punctuation and symbols accurately.
 Navigate and edit text efficiently with keyboard controls.
 Use essential productivity shortcuts.
 Measure typing speed and accuracy responsibly.
 Produce professional copy-typed documents and numeric entries.

Lesson 4: Home Row and Finger Placement
Introduction
The home row is the basic resting position used in touch typing. On a QWERTY keyboard the left hand rests
on A-S-D-F and the right hand on J-K-L-semicolon.

Learning Objectives
 Explain the main ideas in home row and finger placement.
 Complete the practical exercise for home row and finger placement.
 Apply accurate, comfortable and professional keyboard technique.

Teaching Content
Key point: The F and J keys commonly have raised guides for the index fingers.

Key point: Each finger returns to its home position after reaching another key.

Key point: Thumbs are used mainly for the Space bar.

Key point: Hands should remain relaxed; forceful keystrokes do not improve speed.

 Figure 4: Instructional visual for Home Row and Finger Placement.

Step-by-Step Guided Practical
1. Place left fingers on A S D F and right fingers on J K L ;.
 

 
2. Find F and J by touch using the raised guides.

3. Type: asdf jkl; repeatedly at a slow rhythm.

4. Add spaces between groups without looking down as much as possible.

Ethan Digital Academy Case Study
Home-row practice gives Academy learners a consistent starting point for later speed-building exercises.

Lesson 5: Home Row Drills and Rhythm
Introduction
Typing rhythm means pressing keys at a steady pace. Smooth rhythm usually produces better accuracy
than rushing.

Learning Objectives
 Explain the main ideas in home row drills and rhythm.
 Complete the practical exercise for home row drills and rhythm.
 Apply accurate, comfortable and professional keyboard technique.

Teaching Content
Key point: Begin slowly enough to avoid repeated errors.

Key point: Use light, even keystrokes.

Key point: Return fingers to home row after each reach.

Key point: Practise short sessions regularly rather than one long, exhausting session.

Step-by-Step Guided Practical
1. Type: asdf jkl; 10 times.

2. Type: sad lad fall ask flask.

3. Pause, reset hand position and repeat.

4. Count errors and correct the technique rather than simply increasing speed.

Lesson 15: Typing Accuracy and Error

Learning Objectives

Teaching Content
Key point: Slow down when a particular key combination repeatedly causes errors.

Key point: Practise weak words or letter patterns separately.

Final Examination - 100 Marks
Section A - Keyboard Knowledge (20 marks)
Explain keyboard zones, home row, modifier keys, navigation keys and numeric-entry options.

Section B - Technique and Accuracy (20 marks)
Explain posture, finger placement, rhythm, error reduction and why accuracy comes before speed.

Section C - Editing and Shortcuts (20 marks)
Describe Backspace, Delete, selection, navigation and at least six common productivity shortcuts.

Section D - Practical Typing (20 marks)
Complete an instructor-provided copy-typing and numeric-entry exercise with emphasis on accuracy.

Section E - Speed and Improvement Planning (20 marks)
Explain WPM, accuracy measurement, practice planning and how a learner can track personal
improvement.

 

 

Course Completion Outcome
After successful completion, the learner should be able to use a computer keyboard confidently, apply
home-row touch-typing principles, enter letters and numbers accurately, use punctuation and symbols,
navigate and edit text efficiently, apply common keyboard shortcuts, complete copy-typing tasks and monitor
personal typing speed and accuracy.

Professional Practice Checklist
 Accuracy before speed.
 Relaxed posture and neutral wrists.
 Return fingers toward home row.
 Check names, dates and numbers carefully.
 Use shortcuts only when their effect is understood.
 Practise regularly in short focused sessions.
 Measure improvement against your own earlier performance.
