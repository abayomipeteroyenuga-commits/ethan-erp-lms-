 administrative controls, security bypasses and risky system modifications are
 outside the beginner practical scope.

 

 

Course Introduction
Windows Productivity teaches learners to use the Windows desktop, Start menu, taskbar, File Explorer,
search, window management, shortcuts, clipboard, screenshots, settings, accessibility, notifications,
security, storage and backup features efficiently.

Learning Objectives
 Navigate the Windows desktop, Start menu and taskbar.
 Organise files and folders using File Explorer.
 Use Windows Search effectively.
 Manage multiple application windows.
 Apply useful keyboard shortcuts.
 Capture and manage screenshots responsibly.
 Use normal display, sound and accessibility settings.
 Apply safe everyday Windows security habits.
 Build an organised end-to-end productivity workflow.

After successful completion, the learner should be able to use Windows confidently for everyday academic
and office productivity: navigate the interface, organise files, search efficiently, manage multiple windows,
use shortcuts and clipboard tools, capture screenshots responsibly, adjust normal settings, use accessibility
features, protect sessions, manage storage and maintain an organised backup-aware workflow.

Professional Practice Checklist
 Use clear file and folder names.
 Keep the desktop and Downloads organised.
 Use shortcuts only when their effect is understood.
 Review screenshots before sharing.
 Lock the device when leaving it unattended.
 Use official Windows settings and approved software.
 Keep an independent backup of important work.
