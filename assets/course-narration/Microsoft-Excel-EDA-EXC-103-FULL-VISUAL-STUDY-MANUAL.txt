Microsoft Excel is a spreadsheet application used to organize data, perform calculations, analyse information,
create charts and prepare reports. This course develops practical spreadsheet skills for school, office,
business and professional work.

student records, sales data, attendance, course fees and management dashboards.

LESSON 1: EXCEL FOUNDATIONS AND INTERFACE
Microsoft Excel is a spreadsheet application. A spreadsheet organizes information in a grid and can calculate,
analyse and present that information.

 Figure 1. The main areas of a Microsoft Excel worksheet.

Workbook and Worksheet
A workbook is an Excel file. A workbook can contain one or more worksheets. Each worksheet contains rows
and columns.

Key Interface Areas
 Title bar
 Ribbon and tabs
 Name Box
 Formula Bar
 Worksheet grid
 Sheet tabs
 Status bar and zoom controls

Why Excel Matters
Excel is used for budgets, payroll support, attendance, inventories, sales records, academic scores, financial
analysis and management reporting.

LESSON 2: WORKBOOKS, WORKSHEETS, CELLS AND DATA TYPES
Excel stores information in cells. A cell address combines its column letter and row number, for example B4.

 Figure 2. Excel data types and cell-reference concepts.

Rows, Columns and Ranges
Rows run horizontally and are numbered. Columns run vertically and are lettered. A range is a group of cells,
such as A1:C10.

Common Data Types
 Text - names and labels
 Numbers - quantities and amounts
 Dates and times
 Percentages
 Formulas - expressions beginning with =

Good Data Entry
Keep one type of information per column and use clear headings. Avoid mixing unrelated data in the same
cell.

Step-by-Step Practical
1. Enter headings Name, Course, Fee and Status in A1:D1.

2. Enter five sample learner records.

3. Select the range A1:D6.

4. Rename Sheet1 to Learners.

LESSON 3: ENTERING, EDITING AND MANAGING DATA
Accurate data entry is essential because formulas and reports depend on the values stored in the worksheet.

 Figure 2. Data types and references used during data entry.

Editing Cells
Double-click a cell or use the Formula Bar to edit its contents. Delete clears selected content; Undo reverses
many recent actions.

AutoFill and Fill Handle
The fill handle can copy values, formulas and recognized sequences such as months or numbers.

Find and Replace
Find locates specific content; Replace can change repeated content efficiently. Always review replacements
before applying them widely.

Insert and Delete
Rows, columns and cells can be inserted or deleted. Be careful when formulas depend on the affected range.

LESSON 5: FORMULAS AND OPERATORS
A formula is an instruction Excel calculates. Formulas normally begin with the equals sign (=).

 Figure 4. A worked budget example using formulas.

Arithmetic Operators
 + addition
 - subtraction
 * multiplication
 / division
 ^ exponentiation

Order of Operations
Excel follows mathematical precedence. Parentheses can make the intended calculation clearer.

Using Cell References
Instead of typing values repeatedly, refer to cells. For example, =B2*C2 calculates quantity multiplied by unit
cost.

Formula Safety
Check formulas after copying them. A correct-looking result can still come from an incorrect range.

LESSON 6: CORE FUNCTIONS: SUM, AVERAGE, MAX, MIN AND
COUNT
Functions are predefined formulas that perform common calculations.

 Figure 3. Core Excel formulas and functions.

SUM
Adds numbers. Example: =SUM(D2:D10).

AVERAGE
Returns the arithmetic mean. Example: =AVERAGE(B2:B10).

MAX and MIN
MAX returns the largest value; MIN returns the smallest.

COUNT
Counts cells containing numbers. COUNTA can count non-empty cells.

Function Arguments
The values or ranges inside parentheses are arguments. Always verify that the selected range contains the
intended data.

Step-by-Step Practical
1. Enter ten student scores.

2. Calculate the total with SUM.

3. Calculate the average with AVERAGE.

 

4. Find the highest score with MAX and lowest with MIN.

5. Count the numeric scores with COUNT.

LESSON 7: CELL REFERENCES AND COPYING FORMULAS
Cell references control how formulas behave when copied to other cells.

 Figure 2. Relative, absolute and mixed cell references.

Relative Reference
A1 changes relative to the new position when a formula is copied.

Absolute Reference
$A$1 remains fixed when copied. This is useful for a tax rate, exchange rate or other constant stored in one
cell.

Mixed Reference
A$1 fixes the row; $A1 fixes the column.

Practical Example
If B2 contains an amount and F1 contains a fixed rate, =B2*$F$1 keeps the rate cell fixed when copied
downward.

Step-by-Step Practical
1. Enter five amounts in B2:B6.

2. Enter 7.5% in F1.

3. In C2 type =B2*$F$1.

4. Copy C2 down to C6.

5. Check that every copied formula still points to $F$1.

 

Review Questions
1. What is a relative reference?

2. What is an absolute reference?

3. What does $A1 fix?

4. Why is $F$1 useful for a constant rate?

Assignment

LESSON 8: LOGICAL FUNCTIONS AND IF
Logical functions allow a worksheet to make decisions based on conditions.

 Figure 7. How an IF formula evaluates a condition.

IF Function
The IF function tests a condition and returns one result when TRUE and another when FALSE. Example:
=IF(B2>=50,"Pass","Fail").

Comparison Operators
 > greater than
 < less than
 >= greater than or equal to
 <= less than or equal to
 = equal to
 <> not equal to

AND and OR
AND requires all specified conditions to be true. OR requires at least one specified condition to be true.

Nested Logic
Complex formulas can become difficult to audit. Keep business rules clear and test several cases.

Step-by-Step Practical
1. Enter five scores.

2. Use IF to return Pass for scores of 50 or above and Fail otherwise.

3. Test the formula with scores below, equal to and above 50.

 

4. Add a second condition for a simple eligibility example using AND.

Review Questions

2. What does >= mean?

LESSON 9: SORTING, FILTERING AND EXCEL TABLES
Sorting changes the order of records. Filtering temporarily displays only records that match selected criteria.

 Figure 6. The difference between sorting and filtering.

Sorting
Sort text alphabetically, numbers smallest-to-largest or largest-to-smallest, and dates oldest-to-newest or
newest-to-oldest.

Filtering
Filters help focus on selected categories without deleting other records.

Excel Tables
Converting a range to a table provides structured formatting, filter controls and easier expansion.

Data Integrity
Select the whole dataset before sorting so related values remain on the same row.

Step-by-Step Practical
1. Create a 10-record course list.

3. Filter Status to show Active only.

4. Convert the range to an Excel Table.

LESSON 13: LOOKUP FUNCTIONS
Lookup functions search for a key and return related information from a table.

 Figure 9. Looking up a course code in a reference table.

Lookup Idea
A course code can be used to retrieve a course name or fee from a reference table.

XLOOKUP
In supported Excel versions, XLOOKUP provides a flexible way to search one range and return a value from
another.

VLOOKUP
VLOOKUP is widely used in older workbooks. It searches the first column of a table and returns a value from
a specified column.

Exact Matches
For codes, IDs and other identifiers, exact-match logic is usually appropriate.

Error Handling
If a key is missing, the formula may return an error. Validate the key and consider appropriate error handling.

Step-by-Step Practical
1. Create a reference table with Course Code, Course and Fee.

 Figure 10. From detailed source data to a PivotTable summary.

blank rows.

Rows, Columns, Values and Filters

Refreshing
If source data changes, the PivotTable may need to be refreshed.

PivotCharts
A PivotChart provides a visual summary connected to the PivotTable.

LESSON 15: PAGE LAYOUT, PRINTING AND PDF EXPORT
A correct worksheet can still print badly if page layout is not prepared.

 Figure 4. Portrait and landscape layout concepts also apply to spreadsheet reports.

Print Area
Set a print area when only part of a worksheet should be printed.

Orientation and Margins
Portrait suits many narrow reports; landscape may suit wide tables.

Scaling
Fit-to-page options can help, but excessive shrinking makes text unreadable.

Headers and Footers
Use them for report titles, dates, confidentiality labels or page numbers where appropriate.

PDF Export
Review the final PDF to ensure columns, titles and page breaks appear correctly.

 Numbers stored as text
 Inconsistent date formats

 Misspelled categories

Decision Focus
