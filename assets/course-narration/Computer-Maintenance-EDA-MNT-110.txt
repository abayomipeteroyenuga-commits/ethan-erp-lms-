Course Introduction
Computer Maintenance teaches learners how to keep computers clean, organised, updated, backed up,
secure and reliable. It covers preventive maintenance, safe cleaning, software updates, storage
management, backups, performance monitoring, browser care, battery and peripheral care, troubleshooting,
maintenance records and planning.

Learning Objectives
 Explain preventive and corrective computer maintenance.
 Prepare a safe maintenance workspace.
 Perform safe external cleaning and inspection.
 Use approved operating-system and application maintenance tools.
 Manage storage and backups responsibly.
 Monitor basic performance without unsafe system changes.
 Maintain simple asset and maintenance records.
 Apply a structured troubleshooting and escalation workflow.
 Create a preventive-maintenance plan for a computer lab.

Lesson 1: Introduction to Computer
Maintenance
Introduction
Computer maintenance is the planned care of hardware, software and data so a computer remains reliable,
secure and useful. Preventive maintenance aims to reduce avoidable problems before they interrupt work.

Learning Objectives
 Explain the key principles of introduction to computer maintenance.
 Complete the safe guided practical for introduction to computer maintenance.
 Know when a maintenance task should be escalated to authorised technical staff.

Teaching Content
Key point: Maintenance includes inspection, safe cleaning, updates, storage management, backups,
performance checks and record keeping.

Key point: Preventive maintenance is scheduled before a failure; corrective maintenance responds after a
problem appears.

Key point: Beginner learners should focus on safe external care and approved software tools.

Key point: Internal electrical repair, damaged batteries and exposed power components require qualified
personnel.

 

 
 Figure 1: Instructional visual for Introduction to Computer Maintenance.

Step-by-Step Guided Practical
1. Inspect an authorised computer without opening it.

2. Record visible condition, free storage and update status.

3. List three preventive tasks and three corrective tasks.

4. Create a simple maintenance checklist.

Lesson 2: Maintenance Safety and Preparation
Introduction
Safe maintenance begins before any cleaning or troubleshooting. A dry workspace, correct shutdown and
clear limits reduce risk to both people and equipment.

Learning Objectives
 Explain the key principles of maintenance safety and preparation.
 Complete the safe guided practical for maintenance safety and preparation.
 Know when a maintenance task should be escalated to authorised technical staff.

Teaching Content
Key point: Save work and use normal operating-system shutdown.

Key point: Disconnect external power only when the instructor or manufacturer procedure requires it.

Key point: Never work on wet equipment or damaged electrical cables.

Key point: Do not open power supplies or other hazardous electrical components.

Key point: Use manufacturer guidance for model-specific service procedures.

Lesson 3: External Cleaning of Computers
Introduction
Dust, fingerprints and debris can affect comfort, airflow and appearance. Cleaning must be done with the
equipment in a safe state and with suitable materials.

Learning Objectives
 Explain the key principles of external cleaning of computers.
 Complete the safe guided practical for external cleaning of computers.
 Know when a maintenance task should be escalated to authorised technical staff.

Teaching Content
Key point: Use a soft lint-free cloth for external surfaces.

Key point: Do not spray liquid directly into ports, keyboards or vents.

Key point: Screens require gentle cleaning with a method suitable for the display manufacturer.

Key point: Loose keyboard debris can be removed using safe, non-damaging methods.

Key point: Internal cleaning should be performed only on prepared training equipment by authorised
personnel.

 Figure 3: Instructional visual for External Cleaning of Computers.

5. Confirm no moisture remains before normal use.

Lesson 8: Backup Fundamentals
Introduction
A backup is a separate copy of important data used for recovery after deletion, hardware failure or another
problem.

Learning Objectives
 Explain the key principles of backup fundamentals.
 Complete the safe guided practical for backup fundamentals.
 Know when a maintenance task should be escalated to authorised technical staff.

Teaching Content
Key point: A backup should be separate from the working copy.

Key point: The 3-2-1 idea encourages multiple copies, more than one storage type and one separate copy.

Key point: Cloud sync and backup are related but not always identical; accidental changes may
synchronise too.

Key point: Backups should be protected from unauthorised access.

Key point: A restore test confirms that the backup can actually be used.

 Figure 8: Instructional visual for Backup Fundamentals.

 

 

Step-by-Step Guided Practical
1. Create a harmless practice folder.

2. Copy it to an authorised backup location.

3. Rename one file in the working copy.

4. Restore the original from the backup into a separate test folder.

5. Compare both copies.

Lesson 10: Performance Monitoring Basics
Introduction
Slow performance can come from many causes. Maintenance starts by identifying the symptom and
checking normal resource information rather than making random changes.

Learning Objectives
 Explain the key principles of performance monitoring basics.
 Complete the safe guided practical for performance monitoring basics.
 Know when a maintenance task should be escalated to authorised technical staff.

Teaching Content
Key point: Task Manager or similar tools can show CPU, memory, storage and application activity.

Key point: High usage during a demanding task is not automatically a fault.

Key point: Too many applications can reduce available memory.

Key point: Very low free storage can affect updates and normal operation.

Key point: Avoid changing advanced system settings unless authorised and understood.

 Figure 10: Instructional visual for Performance Monitoring Basics.

 

 

Step-by-Step Guided Practical
1. Open Task Manager or the system monitor.

2. Observe CPU and memory at idle.

3. Open a normal application and observe the change.

4. Close it and confirm resource use settles.

5. Record observations without ending unknown system processes.

Lesson 11: Startup and Shutdown Good
Practice
Introduction
Correct startup and shutdown help protect open work and allow the operating system to complete normal
processes.

Learning Objectives
 Explain the key principles of startup and shutdown good practice.
 Complete the safe guided practical for startup and shutdown good practice.
 Know when a maintenance task should be escalated to authorised technical staff.

Teaching Content
Key point: Use the operating system's shutdown command rather than routinely cutting power.

Key point: Restart is useful after some updates or temporary software issues.

Key point: Sleep preserves a session but is not the same as shutdown.

Key point: Unexpected power loss can interrupt writes and cause data loss.

Key point: A UPS can provide time for safe shutdown during short outages.

Step-by-Step Guided Practical
1. Identify Shut down, Restart and Sleep options.

2. Explain when each is appropriate.

3. Save a practice file.

4. Restart the computer if authorised.

5. Reopen the file and confirm it is intact.

Professional Practice Checklist
 Save work and shut down correctly before relevant maintenance.
 Keep liquids away from equipment openings.
 Use official update and software sources.
 Back up important data before major changes.
 Do not disable security controls to force unknown software to run.
 Stop using damaged electrical equipment or swollen batteries.
 Document maintenance actions and escalate hazardous faults.
