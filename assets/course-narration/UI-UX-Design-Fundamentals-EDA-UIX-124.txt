ETHAN DIGITAL ACADEMY

UI/UX DESIGN FUNDAMENTALS

FULL VISUAL STUDY MANUAL

Human-centred design standard: use consent-based research, protect private information, avoid deceptive interface patterns, design accessible alternatives where practical, and never use prototypes to mislead users about real services or transactions.

Course Introduction

UI/UX Design Fundamentals teaches learners how to understand users, define problems, organise information, create wireframes and interfaces, design interactions, consider accessibility, build prototypes, test usability and document improvements. The focus is practical human-centred design rather than coding.

Learning Objectives

Explain the difference and relationship between UI and UX.

Define user problems and research questions.

Create personas, journeys and task flows.

Organise information and navigation.

Build low-fidelity wireframes.

Apply interface hierarchy and interaction patterns.

Design accessible and responsive interfaces.

Prototype and test key tasks.

Complete a documented UI/UX product project.

Lesson 1: Introduction to UI/UX Design

Introduction

Introduction to UI/UX Design develops a practical part of the human-centred product design process. Learners connect user needs with clear information, predictable interactions and interfaces that support successful task completion.

Learning Objectives

Explain the main principles of introduction to ui/ux design.

Complete a guided UI/UX practical for introduction to ui/ux design.

Apply the lesson to an Ethan Digital Academy learner experience.

Teaching Content

UX principle: Begin with a real user goal rather than visual decoration.

UX principle: Make important information and actions easy to find.

UX principle: Use familiar patterns and clear labels where they improve understanding.

UX principle: Provide feedback so users know what happened after an action.

UX principle: Review designs for accessibility, privacy and avoidable friction.

Figure 1: Original instructional visual for Introduction to UI/UX Design.

Step-by-Step Guided Practical

1. Choose one learner task such as finding a course or viewing an enrolled lesson.

2. Write the user goal and the information needed to complete it.

3. Sketch the flow or screen structure before adding visual styling.

4. Create a simple wireframe or prototype using instructor-approved tools.

5. Review clarity, accessibility and task completion; record one improvement.

Ethan Digital Academy Case Study

Ethan Digital Academy can apply introduction to ui/ux design to improve the learner portal so students, professionals and business owners can understand what to do without developer-oriented language or unnecessary interface clutter.

Review Questions

Course Completion Outcome

After successful completion, the learner should be able to understand a user problem, conduct basic ethical research, create personas and flows, organise information, build wireframes and prototypes, apply clear UI patterns, consider accessibility and responsive behaviour, run a basic usability test, iterate from findings and document a practical product design solution.

Professional Practice Checklist

Start with user goals, not decoration.

Use consent-based research and protect private information.

Use clear labels and predictable navigation.

Design visible feedback and recoverable error states.

Avoid deceptive or manipulative interface patterns.

Check contrast, labels and basic accessibility.

Test key tasks with realistic scenarios.

Document findings and revisions.

Keep design files and handoff notes organised.
